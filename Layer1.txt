CREATE OR ALTER FUNCTION dbo.fn_NormalizeSQL(@sql NVARCHAR(MAX)) RETURNS NVARCHAR(MAX) WITH RETURNS NULL ON NULL INPUT AS BEGIN
DECLARE @s NVARCHAR(MAX)=@sql,@i INT,@j INT;
WHILE 1=1 BEGIN SET @i=CHARINDEX(N'/*',@s); IF @i=0 BREAK; SET @j=CHARINDEX(N'*/',@s,@i+2); IF @j=0 BEGIN SET @s=LEFT(@s,@i-1); BREAK; END SET @s=STUFF(@s,@i,(@j-@i)+2,N' '); END
WHILE 1=1 BEGIN SET @i=CHARINDEX(N'--',@s); IF @i=0 BREAK; SET @j=CHARINDEX(NCHAR(10),@s,@i); IF @j=0 SET @j=CHARINDEX(NCHAR(13),@s,@i); IF @j>0 SET @s=STUFF(@s,@i,(@j-@i),N' '); ELSE SET @s=LEFT(@s,@i-1); END
SET @s=REPLACE(REPLACE(REPLACE(@s,NCHAR(9),N' '),NCHAR(13),N' '),NCHAR(10),N' ');
WHILE CHARINDEX(N'  ',@s)>0 SET @s=REPLACE(@s,N'  ',N' '); RETURN UPPER(LTRIM(RTRIM(@s))); END
GO
CREATE OR ALTER FUNCTION dbo.fn_ObjectHash(@def NVARCHAR(MAX)) RETURNS VARBINARY(64) AS BEGIN RETURN HASHBYTES('SHA2_256',ISNULL(dbo.fn_NormalizeSQL(@def),N'')); END
GO
CREATE OR ALTER FUNCTION dbo.fn_NormalizeForHash(@def NVARCHAR(MAX)) RETURNS NVARCHAR(4000) WITH RETURNS NULL ON NULL INPUT AS BEGIN
RETURN CAST(REPLACE(REPLACE(REPLACE(REPLACE(REPLACE(REPLACE(REPLACE(REPLACE(REPLACE(UPPER(@def),N'--'+NCHAR(10),N' '),N'--'+NCHAR(13),N' '),N'/*',N' '),N'*/',N' '),NCHAR(9),N' '),NCHAR(13),N' '),NCHAR(10),N' '),N'[',N''),N']',N'') AS NVARCHAR(4000)); END
GO
CREATE OR ALTER FUNCTION dbo.fn_NormalizeForSearch(@def NVARCHAR(MAX)) RETURNS NVARCHAR(MAX) WITH RETURNS NULL ON NULL INPUT AS BEGIN
RETURN REPLACE(REPLACE(REPLACE(REPLACE(REPLACE(REPLACE(REPLACE(REPLACE(REPLACE(REPLACE(REPLACE(REPLACE(UPPER(@def),N'--'+NCHAR(10),N' '),N'--'+NCHAR(13),N' '),N'/*',N' '),N'*/',N' '),NCHAR(9),N' '),NCHAR(13),N' '),NCHAR(10),N' '),N'[',N''),N']',N''),N'DBO.',N''),N'SALES.',N''),N'HR.',N''); END

CREATE VIEW dbo.vwSingleColumnPKs AS
SELECT pk.DatabaseName,pk.SchemaName,pk.TableName,pk.ColumnName,pk.DataType,dtf.FamilyCode
FROM dbo.TablePKColumns pk JOIN dbo.DiscoveryDataTypeFamily dtf ON dtf.DataType=pk.DataType
WHERE NOT EXISTS(SELECT 1 FROM dbo.TablePKColumns pk2 WHERE pk2.DatabaseName=pk.DatabaseName AND pk2.SchemaName=pk.SchemaName AND pk2.TableName=pk.TableName AND pk2.Ordinal=2);
GO
CREATE VIEW dbo.vwDiscoveryCandidateColumns AS
SELECT DatabaseName,SchemaName,TableName,ColumnName FROM dbo.DiscoveryCandidateColumns GROUP BY DatabaseName,SchemaName,TableName,ColumnName;
GO

CREATE TABLE dbo.VirtualFKDetails(

    MatchCoveragePct DECIMAL(9,4) NULL,
    OrphanRows BIGINT NULL,
    DistinctChildKeys BIGINT NULL,
    GatedBy NVARCHAR(16) NOT NULL, -- 'Evidence' or 'Sample'
    IsPromoted BIT NOT NULL DEFAULT 1,
    IsSelfReference BIT NOT NULL DEFAULT 0,
    CreatedAt DATETIME2 NOT NULL DEFAULT SYSUTCDATETIME(),
    CONSTRAINT UQ_VFKDetails UNIQUE(DatabaseName,SchemaName,TableName,FKColumn));

DECLARE @MinEv2 INT=CAST(ISNULL((SELECT ParamValue FROM dbo.DiscoveryParameters WHERE ParamName=N'VirtualFK_MinEvidence'),N'25')AS INT);
DECLARE @MinRows2 INT=CAST(ISNULL((SELECT ParamValue FROM dbo.DiscoveryParameters WHERE ParamName=N'VirtualFK_MinRows'),N'10')AS INT);
DECLARE @MinDistinct2 INT=CAST(ISNULL((SELECT ParamValue FROM dbo.DiscoveryParameters WHERE ParamName=N'VirtualFK_MinDistinct'),N'2')AS INT);
DECLARE @MaxOrphan2 DECIMAL(9,4)=CAST(ISNULL((SELECT ParamValue FROM dbo.DiscoveryParameters WHERE ParamName=N'VirtualFK_MaxOrphanPct'),N'10')AS DECIMAL(9,4));

IF OBJECT_ID('tempdb..#VFKScored')IS NOT NULL DROP TABLE #VFKScored;
SELECT cre.EvidenceId,cre.DatabaseName,cre.SchemaName,cre.TableName,cre.FKColumn,
    cre.ReferencedSchema,cre.ReferencedTable,cre.ReferencedColumn,
    cre.MatchCoveragePct,cre.OrphanRows,cre.DistinctChildKeys,
    (CASE WHEN cre.SameName=1 THEN 20 ELSE 0 END
    +CASE WHEN cre.SameDatatype=1 THEN 15 ELSE 0 END
    +CASE WHEN cre.SameDatatypeFamily=1 AND cre.SameDatatype=0 THEN 5 ELSE 0 END
    +CASE WHEN cre.CompositeName=1 THEN 15 ELSE 0 END
    +CASE WHEN cre.SupportingIndexCount>0 THEN 10 ELSE 0 END
    +CASE WHEN cre.ReferencedByUniqueConstraint=1 THEN 10 ELSE 0 END
    +CASE WHEN cre.ObjectReferenceCount>0 THEN 15 ELSE 0 END) AS EvidenceScore
INTO #VFKScored
FROM dbo.ColumnRelationshipEvidence cre;

-- Gate: pass on evidence score alone; only fall back to the sample-quality
-- check (rows/distinct/orphan%) when the evidence score isn't already decisive.
IF OBJECT_ID('tempdb..#VFKGated')IS NOT NULL DROP TABLE #VFKGated;
SELECT *,
    CASE WHEN EvidenceScore>=@MinEv2 THEN N'Evidence' ELSE N'Sample' END AS GatedBy
INTO #VFKGated
FROM #VFKScored
WHERE EvidenceScore>=@MinEv2
   OR (ISNULL(DistinctChildKeys,0)>=@MinDistinct2
       AND ISNULL(DistinctChildKeys,0)>=@MinRows2
       AND ISNULL(MatchCoveragePct,0)>=(100.0-@MaxOrphan2));

-- Best parent only per (child table, FK column): highest score, then best coverage.
IF OBJECT_ID('tempdb..#VFKBest')IS NOT NULL DROP TABLE #VFKBest;
SELECT *,ROW_NUMBER()OVER(PARTITION BY DatabaseName,SchemaName,TableName,FKColumn
    ORDER BY EvidenceScore DESC,ISNULL(MatchCoveragePct,0)DESC) AS rn
INTO #VFKBest
FROM #VFKGated;

INSERT INTO dbo.VirtualFKDetails(DatabaseName,SchemaName,TableName,FKColumn,ReferencedSchema,ReferencedTable,ReferencedColumn,EvidenceScore,MatchCoveragePct,OrphanRows,DistinctChildKeys,GatedBy,IsPromoted,IsSelfReference)

    CASE WHEN SchemaName=ReferencedSchema AND TableName=ReferencedTable THEN 1 ELSE 0 END
FROM #VFKBest WHERE rn=1;

TRUNCATE TABLE dbo.DiscoveryCandidateColumns;
INSERT dbo.DiscoveryCandidateColumns(DatabaseName,SchemaName,TableName,ColumnName,Source)
SELECT DatabaseName,SchemaName,TableName,ColumnName,
    CASE WHEN SUM(CASE WHEN Source=N'PK' THEN 1 ELSE 0 END)>0 THEN N'PK'
         WHEN SUM(CASE WHEN Source=N'FKChild' THEN 1 ELSE 0 END)>0 THEN N'FKChild'
         WHEN SUM(CASE WHEN Source=N'FKParent' THEN 1 ELSE 0 END)>0 THEN N'FKParent'
         WHEN SUM(CASE WHEN Source=N'Index' THEN 1 ELSE 0 END)>0 THEN N'Index'
         ELSE N'FKRef' END AS Source
FROM(
    SELECT DatabaseName,SchemaName,TableName,ColumnName,N'PK' AS Source FROM dbo.TablePKColumns
    UNION ALL
    SELECT idx.DatabaseName,idx.SchemaName,idx.TableName,LTRIM(RTRIM(REPLACE(REPLACE(c.value(N'.',N'NVARCHAR(128)'),N'[',N''),N']',N''))),N'Index'
    FROM dbo.TableIndexes idx CROSS APPLY(SELECT CAST(N'<x>'+REPLACE(idx.KeyColumns,N',',N'</x><x>')+N'</x>' AS XML))x(raw) CROSS APPLY x.raw.nodes(N'/x')t(c)
    UNION ALL
    SELECT DatabaseName,SchemaName,TableName,ColumnName,N'FKRef' FROM dbo.TableColumns WHERE UPPER(ColumnName)LIKE N'%ID' AND LEN(ColumnName)>=4
    UNION ALL
    SELECT DatabaseName,SchemaName,TableName,REPLACE(REPLACE(FKColumns,N'[',N''),N']',N''),N'FKChild' FROM dbo.TableFKDetails WHERE FKColumns IS NOT NULL
    UNION ALL
    SELECT DatabaseName,ReferencedSchema,ReferencedTable,REPLACE(REPLACE(ReferencedColumns,N'[',N''),N']',N''),N'FKParent' FROM dbo.TableFKDetails WHERE ReferencedColumns IS NOT NULL AND ReferencedSchema IS NOT NULL
)cand
GROUP BY DatabaseName,SchemaName,TableName,ColumnName;
PRINT N'[PHASE 5B] Candidate columns: '+CAST(@@ROWCOUNT AS NVARCHAR(20));
GO
-- ═══ PHASE 6: SUMMARY ═══
PRINT N'[PHASE 6] Summary...';
INSERT dbo.DiscoverySummary(DatabaseName,TotalTables,TotalFKs,TotalIndexes,TotalPKColumns,TablesWithBranchId,TablesWithCompositePK,TablesWithIdentity,TablesWithRowVersion,TablesWithGuidPK,TablesWithoutPrimaryKey,TablesWithData,MissingSamplesForTablesWithData,TotalRows)
SELECT d.DatabaseName,COUNT(DISTINCT d.SchemaName+N'.'+d.TableName),ISNULL(fk.Cnt,0),ISNULL(ix.Cnt,0),ISNULL(pk.Cnt,0),SUM(CASE WHEN d.HasBranchId=1 THEN 1 ELSE 0 END),SUM(CASE WHEN d.CompositePK=1 THEN 1 ELSE 0 END),SUM(CASE WHEN d.HasIdentity=1 THEN 1 ELSE 0 END),SUM(CASE WHEN d.HasRowVersion=1 THEN 1 ELSE 0 END),SUM(CASE WHEN d.IsGuidPK=1 THEN 1 ELSE 0 END),SUM(CASE WHEN d.PKDataType IS NULL THEN 1 ELSE 0 END),SUM(CASE WHEN d.HasData=1 THEN 1 ELSE 0 END),0,SUM(d.[RowCount])
FROM dbo.TableDetails d LEFT JOIN(SELECT DatabaseName,COUNT(*)AS Cnt FROM dbo.TableFKDetails GROUP BY DatabaseName)fk ON fk.DatabaseName=d.DatabaseName LEFT JOIN(SELECT DatabaseName,COUNT(*)AS Cnt FROM dbo.TableIndexes GROUP BY DatabaseName)ix ON ix.DatabaseName=d.DatabaseName LEFT JOIN(SELECT DatabaseName,COUNT(*)AS Cnt FROM dbo.TablePKColumns GROUP BY DatabaseName)pk ON pk.DatabaseName=d.DatabaseName GROUP BY d.DatabaseName,fk.Cnt,ix.Cnt,pk.Cnt;
SELECT * FROM dbo.DiscoverySummary ORDER BY DatabaseName;
GO

-- ═══ PHASE 6B: COVERAGE REPORT ═══
PRINT N'[PHASE 6B] Coverage Report...';
DECLARE @CovTpl SYSNAME=(SELECT TOP 1 DBName FROM dbo.DiscoveryConfig WHERE IsActive=1 AND IsTemplate=1);
IF @CovTpl IS NULL SET @CovTpl=(SELECT TOP 1 DBName FROM dbo.DiscoveryConfig WHERE IsActive=1 ORDER BY Ord);
IF OBJECT_ID('tempdb..#TplTables')IS NOT NULL DROP TABLE #TplTables;
SELECT DISTINCT SchemaName,TableName INTO #TplTables FROM dbo.TableDetails WHERE DatabaseName=@CovTpl;
DECLARE @TplCount INT=(SELECT COUNT(*)FROM #TplTables);
INSERT dbo.SourceCoverageMissingTables(DatabaseName,SchemaName,TableName)
SELECT dc.DBName,tt.SchemaName,tt.TableName FROM dbo.DiscoveryConfig dc CROSS JOIN #TplTables tt WHERE dc.IsActive=1 AND dc.IsTemplate=0 AND NOT EXISTS(SELECT 1 FROM dbo.TableDetails td WHERE td.DatabaseName=dc.DBName AND td.SchemaName=tt.SchemaName AND td.TableName=tt.TableName);
INSERT dbo.SourceCoverageReport(DatabaseName,TemplateTableCount,MatchedTableCount,MissingTableCount,CoveragePct)
SELECT dc.DBName,@TplCount,@TplCount-ISNULL(m.MC,0),ISNULL(m.MC,0),ISNULL(CAST(100.0*(@TplCount-ISNULL(m.MC,0))/NULLIF(@TplCount,0) AS DECIMAL(5,2)),0)
FROM dbo.DiscoveryConfig dc LEFT JOIN(SELECT DatabaseName,COUNT(*)AS MC FROM dbo.SourceCoverageMissingTables GROUP BY DatabaseName)m ON m.DatabaseName=dc.DBName WHERE dc.IsActive=1 AND dc.IsTemplate=0;
SELECT * FROM dbo.SourceCoverageReport ORDER BY CoveragePct ASC;
SELECT * FROM dbo.SourceCoverageMissingTables ORDER BY DatabaseName,SchemaName,TableName;
DROP TABLE #TplTables;
GO

-- ═══ PHASE 6C: CROSS-DATABASE PRESENCE ═══
PRINT N'[PHASE 6C] Cross-Database Presence...';
DECLARE @cDef NVARCHAR(MAX)=N'',@iCol NVARCHAR(MAX)=N'',@sExp NVARCHAR(MAX)=N'',@rBit NVARCHAR(MAX)=N'';
SELECT @cDef+=N', '+QUOTENAME(Alias)+N' BIT NOT NULL DEFAULT 0',@iCol+=N', '+QUOTENAME(Alias),@sExp+=N', MAX(CASE WHEN td.DatabaseName=N'''+REPLACE(DBName,'''','''''')+N''' THEN 1 ELSE 0 END) AS '+QUOTENAME(Alias),@rBit+=CASE WHEN DatabaseRole=N'Region' THEN N'+CAST('+QUOTENAME(Alias)+N' AS INT)' ELSE N'' END
FROM(SELECT DBName,DatabaseRole,CASE WHEN IsTemplate=1 THEN N'ExistsInTemplate' WHEN IsHO=1 THEN N'ExistsInHO' ELSE N'ExistsIn'+CASE WHEN DBName LIKE N'db%' THEN STUFF(DBName,1,2,N'') ELSE DBName END END AS Alias FROM dbo.DiscoveryConfig WHERE IsActive=1)C;
DECLARE @rc NVARCHAR(200)=ISNULL(STUFF(@rBit,1,1,N''),N'0');
DECLARE @sql NVARCHAR(MAX)=N'CREATE TABLE dbo.TablePresence(SchemaName SYSNAME NOT NULL,TableName SYSNAME NOT NULL'+@cDef+N',RegionCount AS ('+@rc+N'),CONSTRAINT PK_TablePresence PRIMARY KEY(SchemaName,TableName));';
EXEC sp_executesql @sql;
SET @sql=N'INSERT dbo.TablePresence(SchemaName,TableName'+@iCol+N')SELECT td.SchemaName,td.TableName'+@sExp+N' FROM dbo.TableDetails td GROUP BY td.SchemaName,td.TableName;';
EXEC sp_executesql @sql;
DECLARE @Msg NVARCHAR(MAX) = CAST((SELECT COUNT(*)FROM dbo.TablePresence)AS NVARCHAR(20));
PRINT N'[PHASE 6C] Presence records: '+@Msg;
GO

-- ═══ PHASE 7: SCHEMA DRIFT ═══
PRINT N'[PHASE 7] Schema Drift...';
INSERT dbo.SchemaDriftMatrix(SchemaName,TableName,ColumnName,DriftType,DriftSeverity)
SELECT SchemaName,TableName,ColumnName,N'TYPE_MISMATCH',N'ERROR'
FROM dbo.TableColumns GROUP BY SchemaName,TableName,ColumnName HAVING COUNT(DISTINCT DataType)>1;
INSERT dbo.SchemaDriftMatrix(SchemaName,TableName,ColumnName,DriftType,DriftSeverity)
SELECT d.SchemaName,d.TableName,d.ColumnName,N'NULLABLE_MISMATCH',N'WARNING'
FROM(SELECT SchemaName,TableName,ColumnName FROM dbo.TableColumns GROUP BY SchemaName,TableName,ColumnName HAVING COUNT(DISTINCT CAST(IsNullable AS INT))>1)d
WHERE NOT EXISTS(SELECT 1 FROM dbo.SchemaDriftMatrix s WHERE s.SchemaName=d.SchemaName AND s.TableName=d.TableName AND s.ColumnName=d.ColumnName);
DECLARE @Msg NVARCHAR(MAX) = CAST((SELECT COUNT(*)FROM dbo.SchemaDriftMatrix)AS NVARCHAR(20));
PRINT N'[PHASE 7] Drift items: '+@Msg;
GO
